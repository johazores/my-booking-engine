# Product Roadmap

Work should continue one coherent vertical slice at a time, following product dependencies.

## Implemented

- Provider-agnostic flight-search application boundary.
- RapidAPI flight-search adapter with safe failure handling.
- Normalized flight offers before UI rendering.
- Centralized flight-search validation.
- Safe local environment template and ignored local credential files.

## Next

1. Database and organization/tenant model with enforced tenant ownership.
2. Authentication and organization membership.
3. Roles and permission checks.
4. Persistent authenticated application shell.
5. Tenant settings and branding.
6. Customer management.
7. Internal inventory and availability.
8. Pricing and complete internal booking flow.
9. Payments and booking management.
10. Tenant-configurable provider integrations.

Do not start lower-priority provider expansion while foundational tenant and booking dependencies remain incomplete.
